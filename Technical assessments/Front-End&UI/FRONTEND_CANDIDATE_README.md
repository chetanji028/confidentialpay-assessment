# ConFiPay Frontend Developer Skill Test

## For Candidates: How to Get Started

We've prepared a practical frontend task for you. Here's everything you need:

### 📋 Documents to Read (in order)

1. **FRONTEND_SKILL_TEST.md** - Read this first. This is your task.
2. **FRONTEND_SKILL_TEST_REFERENCE.md** - Component and pattern reference while you work

### ⏱️ Timeline

- **Duration:** 1 to 1.5 hours
- **Focus:** One screen improvement (quality > quantity)
- **Deliverable:** Code changes + brief explanation note

### 🚀 Getting Started

The task requires you to work with the actual project code. You'll need to:

1. Review `src/pages/TreasuryPage.tsx` to understand the current state
2. Identify the primary UX issue
3. Plan and implement your improvement
4. Verify it works at different screen sizes
5. Document your changes

We've provided a reference guide (FRONTEND_SKILL_TEST_REFERENCE.md) that shows available components, icons, and common patterns.

### 📝 Deliverables

- Modified `src/pages/TreasuryPage.tsx` (or related files)
- Brief explanation (3-5 sentences) describing:
  - What issue you prioritized
  - Your specific improvement
  - Why it improves the user experience

### ✅ What We're Looking For

- Thoughtful problem-solving
- Clean, consistent code
- Awareness of accessibility and responsive design
- Ability to work within existing component systems
- Polished, intentional implementation

### ❓ Questions?

Refer to FRONTEND_SKILL_TEST_REFERENCE.md for:
- Available components and their variants
- Tailwind classes
- Icon library
- Form patterns
- Accessibility guidelines
